gl4b Homelab Architecture

Single-host Proxmox VE virtualization platform running OPNsense routing, split-horizon Technitium DNS, Authentik SSO, Caddy reverse proxy, and containerized media/monitoring stacks across six isolated VLANs under home.gl4b.xyz.

Zero Public Exposure

No inbound ports are opened to the internet and remote VPN access is currently deferred. All services resolve strictly on the internal LAN via split-horizon DNS with valid Let's Encrypt TLS certificates.

Redundant Local DNS

Primary Technitium DNS runs as an LXC on Proxmox (10.0.10.2) with secondary AXFR replication to a physical Raspberry Pi (10.0.10.3), keeping name resolution alive during host maintenance.

Strict VLAN Isolation

Every Docker VM lives on a single VLAN without multi-homing. Cross-VLAN traffic is denied by default in OPNsense, permitting only four explicit service pathways.

Architectural Decisions & Hardware Baseline

Core Design Decisions

  • Domain & Certificates: gl4b.xyz is registered at Namecheap with DNS hosted on Cloudflare, enabling automated DNS-01 challenges for Caddy wildcard certs (*.home.gl4b.xyz) and Proxmox ACME.
  • Single-VLAN VMs: Services Docker VM resides strictly on VLAN 10; Media Docker VM resides strictly on VLAN 40. No VM bridges multiple VLANs.
  • Backup Strategy: Dedicated Proxmox Backup Server (PBS) is deferred in favor of scheduled nightly vzdump full-image backups to a secondary local disk (3 copies retained).
  • Break-Glass Access: Every Authentik-protected app retains a local admin account to prevent lockout during SSO outages.

Hardware Assumptions

  • Proxmox Host: Intel CPU with integrated GPU (QuickSync) passed through to Jellyfin for hardware transcoding.
  • Host NICs: Dual network interfaces — one dedicated WAN uplink and one 802.1Q VLAN trunk to the switch.
  • Switching & Wireless: TP-Link TL-SG108E managed switch (VLAN 20 carried untagged as switch VLAN 1) paired with a VLAN-capable Access Point.
  • Out-of-Band DNS Node: Dedicated Raspberry Pi on VLAN 10 running secondary Technitium DNS.
