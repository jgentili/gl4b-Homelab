Risk Register & Mitigation Matrix

Identified Risk Operational Impact Current Mitigation Future Upgrade Path
Virtualized Router
(OPNsense on Proxmox)		 Proxmox host downtime takes down routing, DHCP, and management access across all VLANs. Crash cart (monitor/keyboard) attached to host; OPNsense set to boot first; recovery laptop with static 10.0.20.x IP ready to plug into a Management switch port. Migrate OPNsense to dedicated bare-metal firewall hardware.
No Proxmox Backup Server Full-image backups only; no block-level deduplication or automated verification. Nightly scheduled vzdump backups to a secondary local disk (retaining 3 copies); manual OPNsense XML config export after every change. Deploy dedicated PBS instance with offsite replication.
Single Proxmox Host Hardware failure halts all VMs and LXC workloads simultaneously. Secondary Technitium DNS runs on an independent Raspberry Pi to preserve LAN DNS resolution. Add a second cluster node or replicate Authentik onto the Raspberry Pi.
No Remote VPN Homelab services are unreachable when away from home. Accepted per current security posture (zero open WAN ports). Deploy WireGuard on OPNsense or Tailscale subnet router without opening inbound ports.
Secret / Token Loss Loss of Cloudflare API token or Authentik secrets halts TLS renewals and SSO logins. Store .env configurations and Cloudflare tokens in a password manager (e.g., self-hosted Vaultwarden). Automated encrypted backup of secrets vault.
Authentik SSO Outage Forward-auth and OIDC logins fail across protected applications. Local break-glass admin accounts maintained in every app; Jellyfin excluded from forward-auth. High-availability Authentik deployment.

Open Action Items

1. Populate IOT_STREAMERS Alias

Assign static DHCP reservations on VLAN 50 for smart TVs and streaming sticks once online, and add their IPs to the IOT_STREAMERS alias in OPNsense so they can reach Jellyfin (:8096) and Caddy (:443).

2. Camera WAN Egress Policy

Decide whether IoT security cameras on VLAN 50 require internet access at all; blocking camera WAN egress completely and recording locally is recommended for tighter privacy and isolation.
