Firewall Policy & Traffic Flows

OPNsense evaluates interface rules top-down (first match wins). Only four cross-VLAN service pathways are permitted; all other inter-VLAN traffic is dropped.

Global Baseline Rule: On every interface except Management (VLAN 20), Rule #0 blocks any → This Firewall except UDP 67/68 (DHCP) and UDP 123 (NTP). If IPv6 is enabled by the ISP, matching IPv6 block rules must be added or IPv6 disabled on VLANs 10, 40, 50, and 60.
