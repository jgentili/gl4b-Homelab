Service Responsibilities & Notes

Routing & DNS Layer

  • OPNsense (Boots First): Stateful firewall, DHCP, and NTP server. Unbound DNS is disabled so port 53 remains clear. Config exported after every change.
  • Technitium DNS Pair: Authoritative split-horizon server for home.gl4b.xyz with ad/tracker blocklists. Only proxmox and the *.home.gl4b.xyz wildcard require A records; AXFR zone transfers are restricted strictly to the secondary Raspberry Pi.

Edge Proxy & Authentication

  • Caddy (VLAN 40): Sole HTTPS ingress for *.home.gl4b.xyz using a Let's Encrypt wildcard certificate via Cloudflare DNS-01 challenge.
  • Authentik SSO: Operates as an OIDC provider for Proxmox, Homarr, and Jellyfin, and as a Caddy forward-auth outpost for Uptime Kuma and Pulse. Jellyfin bypasses forward-auth so native TV/mobile clients can authenticate cleanly.

Media Stack (VLAN 40)

  • Jellyfin (Unprivileged LXC): Intel iGPU passed through via a single dev0: mapping for QuickSync transcoding; media dataset bind-mounted read-only.
  • Media Docker VM: Runs Sonarr, Radarr, Prowlarr, and download client routed through a Gluetun VPN container, sharing storage with Jellyfin.

Observability & Dashboard

  • Uptime Kuma: Polls service ports and URLs every 60 seconds and sends alerts via ntfy/email.
  • Pulse: Monitors Proxmox node, VM/LXC, storage, and backup health using a read-only PVEAuditor API token.
  • Homarr: Central landing dashboard aggregating status widgets and quick links.
